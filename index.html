เชื่อมต่อ Firebase Realtime Database

ซิงก์ข้อมูลกระแสเงินสดผ่าน Cloud แบบเรียลไทม์ 24 ชม.

ยังไม่ได้เชื่อมต่อ Firebase

ระบบกำลังใช้งานฐานข้อมูล SQLite ในเครื่อง

ขั้นตอนการตั้งค่า Firebase Realtime Database (ทำครั้งเดียว):
  1. ไปที่ Firebase Console และกด "Add project" (สร้างโปรเจกต์ฟรี)
  2. ในเมนูด้านซ้าย เลือก Build > Realtime Database แล้วกด "Create Database"
  3. เลือก Location (แนะนำ Singapore (asia-southeast1))
  4. เลือกโหมดเริ่มต้นเป็น "Start in test mode" หรือไปที่แท็บ Rules ตั้งเป็น: 
    { "rules": { ".read": true, ".write": true } }
  5. ไปที่รูปเฟือง Project settings > General เลื่อนลงมาที่ "Your apps" เลือก Web (</>) แล้วคัดลอกส่วน firebaseConfig มาวางในช่องด้านบนได้เลย!

สร้างลิงก์สำหรับผู้บริหาร (Executive Link)

สำหรับส่งให้ผู้บริหารดูข้อมูลและกราฟได้อย่างเดียว โดยไม่สามารถบันทึกหรือแก้ไขได้

คัดลอกลิงก์เรียบร้อยแล้ว! พร้อมส่งให้ผู้บริหารได้ทันที

คุณสมบัติความปลอดภัยของลิงก์นี้:
  • ดูข้อมูลครบถ้วน: แสดงยอดเงินคงเหลือ รายรับ-จ่าย กราฟเส้นขยายใหญ่ และตัวเลขบนจุดตัดแบบ Realtime
  • ป้องกันข้อมูล 100%: ซ่อนปุ่มบันทึกยอดประจำวัน, ปุ่มแก้ไข, ปุ่มลบข้อมูล และการตั้งค่าระบบทั้งหมด
  • ฟังก์ชันผู้บริหาร: กรองดูตามช่วงวันที่/เดือน, สลับดูรายวัน-สัปดาห์-เดือน, พิมพ์รายงาน และดาวน์โหลด CSV ได้

ติดตั้งแอปลงบนมือถือ (Web App PWA)

ใช้งานเหมือนแอปจริงเต็มจอ ทั้งบน iPhone และ Android

อุปกรณ์ของคุณพร้อมติดตั้งแอปได้ทันทีด้วย 1 คลิก!

สแกน QR Code ด้วยกล้องมือถือ เพื่อเปิดบนมือถือทันที:

ใช้แอปกล้องใน iPhone หรือแอป LINE สแกนเปิดได้ทันที

สำหรับ iPhone / iPad (Safari)
  1. เปิดลิงก์ในแอป Safari
  2. กดปุ่ม แชร์ (Share) ที่แถบด้านล่าง
  3. เลื่อนลงแล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
  4. กดปุ่ม "เพิ่ม" (Add) ที่มุมขวาบน
สำหรับ Android (Chrome / Samsung)
  1. เปิดลิงก์ในแอป Google Chrome
  2. กดปุ่มเมนู 3 จุด (⋮) ที่มุมขวาบน
  3. เลือก "ติดตั้งแอป" (Install App) หรือ "เพิ่มลงในหน้าจอหลัก"
  4. กด "ติดตั้ง" จะได้ไอคอนแอปบนหน้าจอมือถือทันที
ข้อดีของการติดตั้งแบบ Web App (PWA):
  • เปิดเต็มจอ 100% ไม่มีแถบ URL เหมือนแอปแท้จาก App Store / Play Store
  • ข้อมูลซิงก์สดจาก Firebase อัตโนมัติทุกครั้งที่เปิดใช้งาน
  • ไม่เปลืองพื้นที่ความจุเครื่อง (ขนาดเล็กไม่ถึง 1 MB) และอัปเดตเองอัตโนมัติ
